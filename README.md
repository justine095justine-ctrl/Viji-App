# VIJI SUPER APP 🇹🇿
Afrika ya kidigitali na Viji App

## VIJI INAHUSU NINI?
Viji ni Super App ya Mtanzania. Inakusanya: 
1.  **Viji Stage** - Live + Miyoyo Tsh 10
2.  **Viji Pay** - Wallet ya kutuma/pokea pesa
3.  **Viji Fundi** - Pata fundi karibu nawe
4.  **Viji Booking** - Panga foleni NIDA, Hospital, Benki
